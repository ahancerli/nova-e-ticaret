# Tech stack
- Next.js ^16.4 App Router (breaking changes vs. training data: read `node_modules/next/dist/docs/` before Next-specific code, per `AGENTS.md`). React ^19.3, TypeScript ^6 (strict, `noUncheckedIndexedAccess`), path alias `@/*` → `src/*`.
- Tailwind CSS 4 (`@tailwindcss/postcss`); animations only in `src/app/globals.css` `@theme`.
- Cloudflare: `@opennextjs/cloudflare`, wrangler 4; D1 binding `DB`, R2 binding `ASSETS_BUCKET`. `wrangler.jsonc` D1 fields are generated by `scripts/sync-wrangler.mjs` from `.env*` — don't hand-edit.
- Zod 4 (all input validation), bcryptjs, AG Grid Community 36 (only via `components/ui/DataGrid`), sonner (only via `lib/toast`), lucide-react.
- Package manager npm (`package-lock.json`); ESM (`"type": "module"`).
- Node >= 22.13 required (engines); user default via nvm is latest (v25). Node 18 / 22.9 break tsc/next/tests.
- Tests: node `--experimental-transform-types` + `tests/integration/register.mjs` hooks (mocks server-only, @opennextjs/cloudflare, next/headers, bcryptjs); D1 fake = node:sqlite (`tests/integration/d1-sqlite.mjs`). Schema tests python3. E2E Playwright (Chromium, port 3210, separate DB `.wrangler/e2e`).
- AI module: one active provider (OpenAI / Gemini / Claude); model suggestions `src/modules/ai/domain/providers.ts`, prompts `src/modules/ai/prompts/system-prompts.ts`.
