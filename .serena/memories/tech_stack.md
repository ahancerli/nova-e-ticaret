# Tech stack
- Next.js ^16.4 App Router (breaking changes vs. training data: read `node_modules/next/dist/docs/` before Next-specific code, per `AGENTS.md`). React ^19.3, TypeScript ^6 (strict, `noUncheckedIndexedAccess`), path alias `@/*` → `src/*`.
- Tailwind CSS 4 (`@tailwindcss/postcss`); animations only in `src/app/globals.css` `@theme`.
- Runtime: Node 24 (`node:24-bookworm-slim`), `next.config.ts` `output: "standalone"` + `serverExternalPackages: ["bcryptjs"]` (scripts import it in the container). DB = `node:sqlite` (`src/server/sqlite-driver.ts`, WAL, FK on), media = `FsObjectStorage` (`<key>` + `<key>.meta.json`). Docker Compose: app, scheduler (`scripts/scheduler.mjs` → `/api/cron/*`), `confluentinc/cp-kafka` (KRaft) + `cp-kafka-rest`; prod adds Caddy (HTTPS, `X-Real-IP`) + daily backup. No Cloudflare/wrangler/OpenNext anymore.
- graphql (graphql-js) 17 — only in `src/server/graphql` (no yoga/apollo; client = plain `api()` POST).
- SMTP: own client over `node:net`/`node:tls` (`modules/mail/infrastructure/smtp-client.ts`) — no nodemailer.
- Zod 4 (all input validation), bcryptjs, AG Grid Community 36 (only via `components/ui/DataGrid`), sonner (only via `lib/toast`), lucide-react.
- Package manager npm (`package-lock.json`); ESM (`"type": "module"`).
- Node >= 22.16 required (engines; node:sqlite `columns()` / `backup()`); user default via nvm is latest (v25). Node 18 / 22.9 break tsc/next/tests.
- Tests: node `--experimental-transform-types` + `tests/integration/register.mjs` hooks (mocks server-only, next/headers, bcryptjs); DB = in-memory SQLite through the production `SqliteDriver` (`tests/integration/d1-sqlite.mjs`), app-importing tests set `globalThis.__novaRuntime = { DB }`. Schema tests python3. E2E Playwright (Chromium, port 3210, separate DB `data/e2e`).
- AI module: one active provider (OpenAI / Gemini / Claude); model suggestions `src/modules/ai/domain/providers.ts`, prompts `src/modules/ai/prompts/system-prompts.ts`.
